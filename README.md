# React + Vite Golazo

## Requisitos
- Node.js 18+

## Instalación
\`\`\`bash
git clone <url-del-repo>
cd nombre-proyecto
npm install
cp .env.example .env
npm run dev
\`\`\`

## Estructura
- `src/components`: componentes reutilizables
- `src/pages`: vistas por ruta
- `src/services`: llamadas a API

## Ramas
- `main`: producción
- `dev`: desarrollo activo
